# Parakandla Bharath — Portfolio

A responsive personal portfolio built with plain HTML, CSS and vanilla JavaScript. No framework, package installation or build step is required.

## Run locally
1. Open this repository in VS Code.
2. Open `index.html` in your browser, or use the VS Code Live Server extension.
3. Edit `index.html`, `styles.css` and `script.js`.

## Deployment
This repository is configured for GitHub Pages. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

## Structure
- `index.html` — portfolio content and sections
- `styles.css` — responsive layout and themes
- `script.js` — theme toggle, mobile navigation and footer year
